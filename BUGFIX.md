## Найденные баги и необходимые изменения

1. **Добавление услуги не обновляет интерфейс.**  
   Заменить обычную переменную `selectedServices` на состояние React с помощью `useState`. Для добавления услуг использовать `setSelectedServices`.

2. **Выбранная услуга и количество не сохраняются.**  
   Заменить переменные `selectedServiceId` и `quantity` на состояния `useState`, чтобы значения сохранялись между рендерами. Обновлять их через соответствующие функции установки состояния.

3. **Некорректный расчёт итоговой стоимости.**  
   Рассчитывать `totalPrice` на основе актуального состояния `selectedServices` при каждом рендере. Можно использовать метод `reduce()`.

4. **Удаление услуги не обновляет интерфейс.**  
   Вместо изменения массива через `splice()` создавать новый массив с помощью `filter()` и передавать его в `setSelectedServices`.

5. **Ненадёжное сравнение услуг.**  
   Вместо сравнения объектов через `item.service === service` сравнивать их по уникальному идентификатору: `item.service.id === service.id`.
